# 카드 임팩트·테두리 디자인 개선 설계 (2026-07-31)

카드 도감의 등급 프레임을 포켓몬 카드 느낌으로 강화한다. 구조(정사각 그리드 타일)는
그대로 두고 **테두리·재질**만 화려하게 만들며, 레전드 카드는 상세 오버레이에서
자이로 기울기에 반응하는 홀로그램을 얻는다.

- **대상**: `verse-flutter/` 앱 전용(도감). 오프라인 우선.
- **선행**: `2026-07-31-card-tier-visual-upgrade-design.md`(등급 비주얼·승급 연출 강화, 구현 완료).
  이번 스펙은 그 위에 재질 레이어를 더 얹는다 — 노치·핍 좌표 체계는 건드리지 않는다.
- **아트**: 이번에도 카드 그림(내용물)은 범위 밖. 프레임 재질은 전부 `CustomPainter`/`ShaderMask`로 그린다.
- **신규 의존성**: `sensors_plus` (가속도계로 기기 자세 읽기).

---

## 1. 방향 — 전 등급 재질 사다리 + 레전드 전용 홀로

카드 도감 설계 스펙(`2026-07-23-card-collection-design.md`) §1의 원칙(사람 대신 사물,
저해상도에서도 실루엣 구분)과 등급 비주얼 스펙 §1의 원칙(색·모양·개수로 등급 구별,
상시 애니메이션 없음)을 그대로 지킨다. 이번 스펙이 더하는 것은 정지 상태의 **질감**과,
카드를 눌러 크게 봤을 때만 나타나는 **자이로 반응**이다.

**두 가지 개선을 조합한다:**

1. **전 등급 공통 — 그림창 테두리 + 베벨** — 지금은 카드 그림이 배경색 위에 그냥 떠
   있다. 그림 주위에 안쪽 테두리(그림창)를 둘러 액자 느낌을 주고, 바깥 테두리에는
   좌상단 밝은 면 / 우하단 어두운 면의 베벨 명암을 넣어 입체감을 준다. 브론즈부터
   전부 받는다 — "가장 흔한 카드도 카드답게 보인다"가 목표다.
2. **등급별 재질 차등** — 베벨 위에 등급마다 다른 표면 질감을 얹는다(§2). 브론즈는
   무광 동판, 실버는 브러시드 은, 골드는 유광 금 + 정지 광택, 레전드는 유광 + 프리즘
   홀로(§3에서 자이로로 움직인다).

노치(팔각 실루엣)와 핍 개수는 **좌표·개수 모두 기존 그대로**다. 재질은 그 위에 얹는
장식이지 유일한 신호가 아니라는 원칙(등급 비주얼 스펙 §1)을 그대로 잇는다.

---

## 2. 그림창 테두리 + 베벨 — 전 등급 공통

`CardTierFrame`의 콘텐츠 레이어(`_tintedContent`, 카드 그림/이니셜을 담는 부분) 안쪽에
**그림창 테두리**를 추가한다.

- 콘텐츠 영역 안쪽에 `borderW`의 절반 두께로 얇은 테두리를 하나 더 그린다 —
  등급색보다 어두운 톤(그림자처럼)이라 그림이 "패인 창" 안에 있는 것처럼 보인다.
- 바깥 테두리(기존 `TierDitherPainter`/단색 레이어)에 **선형 베벨**을 얹는다: 테두리
  자체를 두께 방향으로 밝은 색(좌상단 45도) → 어두운 색(우하단 45도) 그라데이션으로
  칠해 도드라져 보이게 한다. 노치가 있는 등급(골드·레전드)은 팔각 외곽선을 따라
  베벨이 꺾인다.
- 브론즈도 받는다 — 지금까지 브론즈는 "변경 없음"이었지만, 이 두 요소(그림창+베벨)는
  전 등급 공통 개선이라 브론즈부터 적용된다. 브론즈와 실버의 차이는 여전히 §3의
  재질(무광 동판 vs 브러시드 은)로만 갈린다.

---

## 3. 등급별 재질

`CardTierFrame`의 테두리 레이어에 재질 페인터를 등급별로 다르게 얹는다. 전부
`CustomPainter`로 그리며 이미지 에셋을 쓰지 않는다.

| 등급 | 재질 | 구현 |
|---|---|---|
| 브론즈 | **동판** — 매트한 구리 베벨 + 미세 그레인 | 베벨(§2) 위에 저대비 노이즈 도트를 성기게 뿌리는 `CopperGrainPainter` |
| 실버 | **브러시드 은** — 방향성 빗살 무늬 + 약한 광택 | 대각선 방향 얇은 명암 줄무늬를 반복 그리는 `BrushedMetalPainter`(기존 `TierDitherPainter`를 대체) |
| 골드 | **유광 금** — 강한 베벨 + 정지 광택 띠 + 코너 장식 | §2 베벨을 더 강하게(대비 높임) + 기존 `TierBracketPainter`(코너 장식) 유지 + 대각선 광택 띠(기존 `_ShinePainter`를 재사용, 정지 상태) |
| 레전드 | 골드 전부 + **프리즘 홀로** | §2·§4의 홀로그램 레이어 추가 |

- **정지 상태에서도 재질 차이가 드러나야 한다** — 애니메이션 없이 스크린샷 한 장으로도
  브론즈~레전드가 구별되는 것이 목표다(그리드에서는 애초에 애니메이션이 없다).
- 실버의 `BrushedMetalPainter`는 기존 `TierDitherPainter`(체커 디더링)를 대체한다.
  체커 패턴은 "재질"이라기보다 "패턴"에 가까웠다 — 방향성 있는 브러시 무늬가 금속감을
  더 준다. 골드·레전드는 브러시드 대신 §2의 강한 베벨 + 광택 띠로 표현하므로
  `BrushedMetalPainter`는 실버 전용이다.
- 골드의 "정지 광택 띠"는 이미 있는 `_ShinePainter`(레전드가 쓰던 것)를 golden 톤으로
  재사용한다. 레전드는 이 정지 띠 대신 §4의 움직이는 홀로그램을 쓴다(둘 다 그리면
  과하다).

## 4. 레전드 전용 — 자이로 홀로그램

**적용 범위: 카드 상세 오버레이(`card_detail_sheet.dart`)에서 레전드 카드를 볼 때만.**
도감 그리드(`CardTile`, 3열 타일)에는 자이로 구독 자체가 생기지 않는다 — 카드가 최대
수십 장 깔리는 화면에서 전부 센서를 구독하면 무겁고, 어차피 타일이 작아 홀로 효과가
잘 안 보인다. 카드를 눌러 크게 봤을 때만 살아있는 카드처럼 반응한다.

### 4-1. 입력 — 가속도계로 기울기 읽기

`sensors_plus`의 `accelerometerEventStream()`을 구독한다. 자이로스코프(각속도)가 아니라
가속도계(중력 방향)를 쓴다 — 필요한 건 "지금 어느 쪽으로 기울었는가"라는 절대 자세이지
회전 속도가 아니다.

- `event.x`, `event.y`를 각각 −1.0~1.0으로 정규화해 홀로그램 레이어의 그라데이션
  오프셋으로 쓴다.
- **저역통과 필터**로 스무딩한다: `smoothed = smoothed * 0.85 + raw * 0.15` 정도의
  지수 이동평균. 손떨림에 반짝임이 지직거리지 않게 한다.
- 값이 바뀔 때마다 홀로 페인터를 다시 그린다(`setState` 대신 `ValueNotifier` +
  `AnimatedBuilder`로 리빌드 범위를 홀로 레이어에만 한정한다 — 상세 오버레이 전체가
  센서 값마다 다시 그려지지 않게).

### 4-2. 매핑 — 기울기 → 무지개 그라데이션

`ShaderMask` 또는 `CustomPainter`로 무지개 대각선 그라데이션을 그리고, 그 위치를
기울기 값만큼 이동시킨다. 기울기가 0이면 그라데이션이 카드 중앙에, 좌우로 기울이면
반대 방향으로 스치듯 이동한다. 색 배열은 낮은 채도의 pastel 무지개(빨강→보라, alpha
0.25 내외)로 두어 그림·텍스트 가독성을 해치지 않는다.

### 4-3. 폴백 — 셋 다 "정지된 골드 광택"으로 떨어진다

아래 세 경우 전부, 레전드 상세는 §3의 골드와 동일한 **정지 광택 띠**로 렌더한다(자이로
레이어만 빠지고 나머지 재질은 그대로). 기능이 항상 완결된 상태를 유지한다.

1. **센서 미지원/구독 실패** — 시뮬레이터, 센서 없는 기기, 권한 거부 등.
   `accelerometerEventStream()` 구독을 `try/catch`로 감싸고, 에러나 첫 이벤트가
   일정 시간(예: 500ms) 안에 안 오면 정지 상태로 확정한다.
2. **"동작 줄이기" 접근성 설정** — `MediaQuery.of(context).disableAnimations`가 `true`면
   애초에 센서를 구독하지 않는다. 기기 움직임에 화면이 반응하는 것 자체가 전정계
   민감한 사용자에게 어지럼증을 유발할 수 있으므로 시스템 설정을 존중한다.
3. **상세 화면이 아닌 경우** — 그리드 타일은 애초에 이 레이어를 갖지 않는다(4번째
   경우가 아니라 설계상 배제, §4 서두 참고).

### 4-4. 생명주기 — 센서 구독 해제

상세 오버레이가 닫히면(`Navigator.pop` 등) 스트림 구독을 즉시 취소한다. 도감 그리드로
돌아간 뒤에는 센서가 전혀 돌지 않는다 — 배터리·불필요한 재빌드를 막는다.

## 5. 재사용 관계

| 필요한 것 | 출처 |
|---|---|
| 노치·핍 좌표 체계 | 기존 `_NotchClipper`, `_pipPositions` — 변경 없음 |
| 베벨 명암 계산 | 신규, `card_tile.dart` 내부 |
| 골드 정지 광택 | 기존 `_ShinePainter`를 golden 톤 인자로 재사용 |
| 레전드 홀로그램 위치 | 신규 `sensors_plus` 구독 + 신규 페인터, `card_detail_sheet.dart` 내부(상세 전용) |
| 접근성 신호 | 기존 `MediaQuery.of(context).disableAnimations` |

## 6. 테스트

- **그림창 테두리**: 전 등급에서 콘텐츠 안쪽에 그림창 테두리 레이어가 존재한다.
- **베벨**: 밝은/어두운 대각선 톤이 좌상단/우하단에 각각 존재한다(페인터 색상 인자 검증).
- **재질별 페인터**: 브론즈=그레인, 실버=브러시드, 골드=광택띠+브래킷, 레전드=골드
  전부+홀로 레이어가 각각의 등급에서만 존재한다. 모르는 조합에서 크래시 없음.
- **노치·핍 회귀**: 기존 팔각 실루엣·핍 개수 테스트가 그대로 통과한다(좌표 미변경).
- **자이로 매핑**: 기울기 입력을 주입했을 때(실제 센서 대신 테스트용 스트림을 주입할
  수 있게 컨트롤러를 분리) 홀로 그라데이션 오프셋이 그 값에 따라 달라진다.
- **스무딩**: 급격한 입력 변화가 한 번에 반영되지 않고 여러 프레임에 걸쳐 수렴한다.
- **폴백 — 구독 실패**: 스트림이 에러를 던져도 크래시 없이 정지 광택으로 렌더된다.
- **폴백 — 접근성**: `disableAnimations`가 `true`면 스트림을 구독하지 않는다(구독
  시도 자체가 없음을 검증).
- **폴백 — 타임아웃**: 500ms 안에 첫 이벤트가 없으면 정지 상태로 확정된다.
- **생명주기**: 상세 오버레이가 닫히면 구독이 취소된다(dispose 이후 스트림 리스너가
  더 이상 남아있지 않음).
- **그리드 비구독**: `CardTile`(그리드 타일)에는 센서 구독 코드 경로가 아예 없다 —
  홀로 레이어·자이로 컨트롤러가 상세 오버레이 전용 위젯에만 존재함을 구조적으로 보장.

## 7. 범위 밖

- **카드 그림(내용물) 아트 제작** — 계속 플레이스홀더/픽셀 아트.
- **그리드에서의 자이로 반응** — 상세 오버레이 전용(§4 서두).
- **진짜 간섭무늬 셰이더(GLSL)** — `ShaderMask`/그라데이션 이동으로 충분히 홀로처럼
  보이므로 채택하지 않는다. 필요하면 후속 과제.
- **탭 트리거 반짝임(등급 비주얼 스펙 §3)과의 통합 튜닝** — 기존 탭 반짝임(골드·레전드
  그리드 타일)은 그대로 두고 건드리지 않는다. 이번 스펙의 홀로그램과 겹쳐 보이는
  화면(그리드 타일 탭 직후 상세가 열리는 순간)의 전환 디테일은 후속 과제.
- **다른 등급의 자이로 반응(골드 등)** — 레전드만 자이로에 반응한다. 골드의 광택은
  정지 상태로 고정(§3).
