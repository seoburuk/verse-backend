# 카드 등급 비주얼·승급 연출 강화 설계 (2026-07-31)

카드 도감의 등급 구분이 테두리 색·노치·핍 정도로 은은하다. 등급 비주얼을 더 강하게 만들고,
등급이 오르는 순간(뒤집기 연출)을 더 체감되게 개선한다.

- **대상**: `verse-flutter/` 앱 전용(도감). 오프라인 우선. 새 데이터·테이블 없음.
- **선행**: `2026-07-23-card-collection-design.md`(도감), `2026-07-24-card-tiers-design.md`(등급),
  `2026-07-30-card-catalog-expansion-design.md`(29장 카탈로그). 전부 구현 완료.
- **아트**: 이번에도 범위 밖. 전부 `CustomPainter`/도형으로 그린다.

---

## 1. 방향 — 정적 강화 + 탭 트리거 반짝임

두 갈래를 조합한다:

1. **정적 레이어 강화(A1)** — 그리드에 가만히 있을 때도 등급 차이가 한눈에 보이게, 실버부터
   재질(디더링)을 더하고 골드·레전드는 장식 요소를 쌓는다.
2. **탭 트리거 반짝임(A2 변형)** — 상시 애니메이션은 두지 않는다(그리드에 카드가 많아지면
   산만하고 배터리 비용도 있다). 대신 **카드를 탭하는 순간**에만 골드·레전드가 반짝이거나
   파티클을 한 번 재생한다 — "만졌을 때 반응하는" 손맛.
3. **승급 연출 차등(B1)** — 획득 연출(`CardFlip`)에서 등급업이면 이전 등급 프레임이 잠깐
   보인 뒤 새 등급으로 전이되는 것을 보여준다. 브론즈 첫 획득은 지금과 동일하게 단순 뒤집기.

색·모양·개수로 등급을 구별하는 기존 원칙(색약 대응)은 그대로 유지한다. 애니메이션은
그 위에 얹는 장식이지 유일한 신호가 아니다.

---

## 2. 정적 레이어 — `CardTierFrame` 확장

`card_tile.dart`의 `CardTierFrame` 내부에 레이어를 추가한다. 노치·핍·테두리 두께는
기존 그대로 두고 아래를 더한다.

| 등급 | 기존 | 추가 |
|---|---|---|
| 브론즈 | 단색 테두리 2px, 핍 0 | 변경 없음 |
| 실버 | 테두리 2px, 핍 2 | 테두리를 **2색 디더링**(밝은 회색 `#C8CDD6` / 어두운 회색 `#7C8290` 체커 픽셀, 2px 격자)으로 |
| 골드 | 노치 4, 테두리 2.5px, 핍 3 | 디더링(금색 톤) + **모서리 ㄱ자 브래킷**(4px 픽셀 선, 네 모서리 안쪽) + 콘텐츠 배경에 등급색 틴트(alpha 0.12) |
| 레전드 | 노치 7, 테두리 3px, 핍 4, 정지 광택 줄 | 디더링(보라 톤) + 브래킷 + 틴트 + **2중 테두리**(바깥 테두리 안쪽에 1px 간격 두고 얇은 두 번째 선) |

- 디더링·브래킷은 `CustomPainter` 신규 클래스(`_TierDitherPainter`, `_TierBracketPainter`)로 그린다.
  에셋 파일 없음.
- 레전드의 기존 대각선 광택 줄(`_ShinePainter`)은 **정지 상태로 유지**한다(상시 애니메이션 아님 —
  §1의 "상시 애니메이션 없음" 원칙과 일관되게, 이미 있던 정지 장식이라 그대로 둔다).
- 골드·레전드만 디더링+브래킷을 받는다. 브론즈·실버는 디더링만(실버) 또는 아무것도(브론즈) —
  단계가 올라갈수록 레이어가 누적되는 형태라 등급 사다리가 시각적으로도 계단식이다.

---

## 3. 탭 트리거 반짝임 — `CardTile`

`CardTile`은 현재 `StatelessWidget`이고 `onTap`으로 상세 시트를 연다. 이를
`StatefulWidget`으로 바꾸지 않고, **탭 시 반짝임 오버레이를 잠깐 띄우는 방식**으로 구현한다.

- **대상**: 골드·레전드 카드만. 브론즈·실버는 탭해도 지금처럼 바로 상세가 열린다
  (반짝일 장식이 없으므로 지연을 줄 이유가 없다).
- **동작**: 탭하면 `onTap`(상세 열기)은 그대로 즉시 실행하되, **탭 지점에 오버레이 애니메이션을
  얹어 250ms 정도 재생**한다. 상세 시트가 열리는 것을 막거나 늦추지 않는다 — 반짝임은 탭한
  카드 타일 자체 위에서 짧게 스치고 사라지는 부가 효과다.
  - **골드**: 대각선 반짝임 줄이 한 번 타일을 가로질러 지나간다(레전드의 정지 광택과 같은 각도,
    애니메이션 버전).
  - **레전드**: 위 + 픽셀 사각 파티클 6~8개가 카드 중심에서 바깥으로 짧게 튀었다 사라진다.
- 구현: `AnimationController`(단발, 재생 후 자동 dispose 불필요 — 위젯 살아있는 동안 재사용)를
  가진 얇은 래퍼(`_TapSparkle`)로 `CardTile`을 감싼다. 탭마다 `controller.forward(from: 0)`.
- 그리드가 이미 `ListView`라 화면 밖 카드는 애니메이션이 도는 일 자체가 없다(빌드 안 됨).
  상시 애니메이션이 아니므로 화면에 여러 장 있어도 idle 비용이 없다.

---

## 4. 승급 연출 — `CardFlip` 차등

`card_repository.dart`의 `revealedTier()`가 이전 등급을 이미 제공한다 — **새 데이터 없음.**
`CardFlip`에 `prevTier` (`CardTier?`) 파라미터를 추가한다. 호출부(`memorize_screen.dart`)에서
`CardStatus`를 만들 때 이미 `revealedTier`를 조회하므로 그 값을 넘기기만 하면 된다.

- **`prevTier == null`(첫 획득/브론즈)**: 기존 그대로 — 뒤집으면 바로 최종 프레임.
- **`prevTier != null`(승급)**: 뒤집기 완료 후,
  1. 먼저 **이전 등급 프레임**으로 앞면이 나타난다.
  2. 400ms 뒤 테두리 색·노치·핍이 **새 등급으로 전이**된다(핍은 늘어난 개수만큼 하나씩
     순차로 찍힌다, 각 80ms 간격).
  3. `HapticFeedback.mediumImpact()` 한 번(전이 시작 시점).
- **레전드로 승급한 경우**: 전이 직후 §3의 파티클 효과를 한 번 재생하고
  `HapticFeedback.heavyImpact()`를 쓴다(mediumImpact 대신).
- 여러 장이 동시에 승급해도(한 절이 여러 카드에 걸림) 지금처럼 `CardFlip`이 나란히 나열되고,
  각자 독립적으로 전이 연출을 재생한다 — 순서를 맞추거나 지연시키지 않는다.

## 5. 재사용 관계

| 필요한 것 | 출처 |
|---|---|
| 이전 등급 | 기존 `CardRepository.revealedTier()` (신규 조회 없음, 이미 `_cardUpgrades` 계산 시 호출됨) |
| 등급별 색·라벨 | 기존 `cardTierColor` / `cardTierLabel` |
| 디더링·브래킷·파티클 페인터 | 신규 `CustomPainter` 3종, `card_tile.dart` 내부 |
| 탭 반짝임 트리거 | 신규 `_TapSparkle` 래퍼, `card_tile.dart` 내부 |
| 승급 전이 상태 | `CardFlip`의 기존 `AnimationController`에 두 번째 구간(전이) 추가 |

## 6. 테스트

- **디더링/브래킷 렌더**: 등급별로 기대하는 레이어(브론즈 없음 / 실버 디더링만 / 골드·레전드
  디더링+브래킷)가 위젯 트리에 존재한다. 모르는 `kind`·등급 조합에서 크래시 없다.
- **탭 반짝임 트리거 범위**: 브론즈·실버 카드는 탭 시 반짝임 오버레이가 재생되지 않는다.
  골드·레전드는 탭할 때만 재생되고, 탭 전에는 정지 상태다(상시 애니메이션 아님을 확인).
- **탭해도 상세가 열림**: 반짝임 재생 여부와 무관하게 `onTap` 콜백이 항상 즉시 호출된다
  (반짝임이 상세 열기를 막거나 지연시키지 않는다).
- **`CardFlip` 전이**: `prevTier == null`이면 기존과 동일하게 즉시 최종 프레임. `prevTier`가
  있으면 이전 등급 프레임이 먼저 나타났다가 새 등급으로 바뀐다. 레전드 승급 시 파티클이
  포함되고 브론즈/실버/골드 승급 시에는 없다.
- **기존 회귀**: 도감·등급 판정·카드 카탈로그 테스트 전부 그대로 통과.

## 7. 범위 밖

- **책장(`BookshelfView`) 개선** — 이번 스펙은 카드 도감만 다룬다.
- **정렬·분류 토글(갈래별 필터 등)** — 카탈로그 확장 스펙 §9-3에 남겨둔 후속 과제.
- **도감 NEW/UP 뱃지** — 별도 후속 검토.
- **카드 아트 제작** — 계속 플레이스홀더.
- **상시 반짝임/움직이는 배경** — 의도적으로 배제(§1).
- **풀스크린 승급 모달** — 기존 완료 화면 흐름을 그대로 쓴다.
